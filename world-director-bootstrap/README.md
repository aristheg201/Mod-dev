# World Director bootstrap

Standalone Fabric 1.21.1 server mod source snapshot for the `feature/world-director` branch.

Restore:

```bash
cat world-director-bootstrap/source.b64.part* | base64 -d > /tmp/world-director-source.tar.gz
echo "6260c995bdb0c05469c848807e7f046092214b7d0898d87e6ebea2219711c941  /tmp/world-director-source.tar.gz" | sha256sum -c -
tar -xzf /tmp/world-director-source.tar.gz
```

The archive expands to `world-director/` and contains the full Gradle project.

Security invariants in this snapshot:

- no Lively dependency or integration;
- no outbound network/telemetry in core;
- no arbitrary console/OP command reward executor;
- HunterCoin is protected and cannot be generated by Director rewards;
- generated economy rewards are typed and policy validated;
- player command actions run only with the player's own command source;
- config scanning is read-only, bounded, path-sandboxed and performed off the Minecraft server thread;
- planning, persistence, scans and reward-ledger work use bounded workers;
- Minecraft-thread work is restricted to short snapshots and final UI/world-affine actions.

The build workflow is `.github/workflows/world-director.yml` and produces a remapped `WorldDirector` artifact after tests pass.
